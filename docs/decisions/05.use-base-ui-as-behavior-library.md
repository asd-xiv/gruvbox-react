# 05. Use Base UI as the one behavior library

**Date**: 2026-11-09

**Problem**:

- `Button` drew another element, eg. a link, through `asChild` and Radix's
  `Slot`
- write-react names Base UI as the one behavior library. Radix came in only for
  `Slot`

**Solution**:

- Draw another element with Base UI's `useRender`: a component takes a `render`
  element, eg. `<Button render={<a href="/docs" />}>`
- Add `@base-ui/react` as a peer dependency, and remove `@radix-ui/react-slot`

**Acknowledgments**:

- An app replaces each `asChild` with `render`
- An app installs `@base-ui/react`, even when it renders no component of Base UI
