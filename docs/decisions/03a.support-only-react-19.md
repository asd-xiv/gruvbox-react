# 03a. Support only React 19

Changes
[03. Forward a ref only from an interactive element](03.forward-ref-from-interactive-element.md).

**Date**: 2026-11-09

**Problem**:

- The peer range `^18 || ^19` kept React 18's `forwardRef` in `Button` and
  `SidebarMenuButton`
- React 19 passes `ref` to a function component as a prop
- React plans to deprecate and remove `forwardRef`

**Solution**:

- Set the peer range of `react` and `react-dom` to `^19`
- Take the ref as a prop: the props type of a component that renders one
  interactive element includes `ref`, eg. `ComponentProps<"button">`
- A layout part still takes no ref: its props type has none

**Acknowledgments**:

- An app on React 18 stays on the previous major
