## `--gvb-radius-md` and `--gvb-radius-lg` are gone

```diff
   /* Border radius - minimal, terminal-inspired */
   --gvb-radius-none: 0;
   --gvb-radius-sm: 2px;
-  --gvb-radius-md: 4px;
-  --gvb-radius-lg: 6px;
```

```css
/* Before */
.panel {
  border-radius: var(--gvb-radius-md);
}

/* After */
.panel {
  border-radius: var(--gvb-radius-sm);
}
```

**If unchanged**:

- `--gvb-radius-md` is undefined, so `border-radius` falls back to `0`, a square
  corner
- The browser and the build report nothing

**Reason**:

- A terminal cell has square corners, so the kit keeps its corners at 2px at
  most
- A token for a 4px or a 6px corner invites a corner the kit forbids

## `rounded-md` and `rounded-lg` are gone

```diff
   /* Border radius */
   .rounded-none {
     border-radius: var(--gvb-radius-none);
   }
   .rounded-sm {
     border-radius: var(--gvb-radius-sm);
   }
-  .rounded-md {
-    border-radius: var(--gvb-radius-md);
-  }
-  .rounded-lg {
-    border-radius: var(--gvb-radius-lg);
-  }
```

```css
/* Before */
.panel {
  composes: rounded-md from global;
}

/* After */
.panel {
  composes: rounded-sm from global;
}
```

**If unchanged**:

- The element gets the `rounded-md` class, but no rule matches it, so its
  corners are square
- CSS Modules reports nothing: it does not check a class composed from global

**Reason**:

- They read the two tokens that v4 removes

## The `transition-*` utilities are gone

```diff
-  /* === TRANSITIONS === */
-
-  .transition-fast {
-    transition: all var(--gvb-transition-fast);
-  }
-  .transition-normal {
-    transition: all var(--gvb-transition-normal);
-  }
-  .transition-slow {
-    transition: all var(--gvb-transition-slow);
-  }
```

```css
/* Before */
.panel {
  composes: transition-fast from global;
}

/* After: name what animates */
@media (prefers-reduced-motion: no-preference) {
  .panel {
    transition: var(--gvb-transition-fast);
    transition-property: background-color;
  }
}
```

**If unchanged**:

- The element gets the `transition-fast` class, but no rule matches it, so it
  changes state at once
- CSS Modules reports nothing: it does not check a class composed from global

**Reason**:

- A module names what it animates, next to the rules that change it
- `all` also animated what the kit never moves, eg. the focus ring
- Button composed `transition-fast` and TriStateSwitch wrote its own
  `transition`, so the utilities forced nothing

## A `<dialog>` keeps the browser's margin

```diff
-  * {
+  *:not(dialog) {
     margin: 0;
   }
```

```css
/* Before */
.drawer {
  inset: 0 0 0 auto;
}

/* After */
.drawer {
  inset: 0 0 0 auto;
  margin: 0;
}
```

**If unchanged**:

- The modal takes `margin: auto`, which centers it in the height that `inset`
  leaves free

**Reason**:

- The browser centers a modal with `margin: auto`
- Josh's reset keeps that margin for the same reason
  ([Josh's custom CSS reset](https://www.joshwcomeau.com/css/custom-css-reset/))
